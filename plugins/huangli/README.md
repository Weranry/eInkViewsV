# 黄历插件 (huangli)

## 简介

基于 `lunar-python` 库的当日黄历视图，展示完整的黄历信息。

## 视图

| 视图 | 尺寸 | 说明 |
| :--- | :--- | :--- |
| huangli | h4xl (800×480) | 完整黄历视图，包含宜忌、吉神凶煞、冲煞、彭祖百忌等 |

## 字段

- 公历日期、星期
- 农历日期（年、月、日）
- 干支纪年（年柱、月柱、日柱）
- 生肖、纳音
- 节气、节日
- 宜、忌
- 吉神宜趋、凶煞宜忌
- 冲煞、彭祖百忌
- 值星、二十八宿、六曜
- 喜神/福神/财神方位、日禄

## 请求示例

```
http://127.0.0.1:5000/huangli/view/huangli?size=h4xl
```
