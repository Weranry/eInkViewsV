# News 新闻插件

报纸排版风格的新闻视图，通过 RSS 抓取多家新闻源。

## 视图种类

| 视图 | 说明 |
| :--- | :--- |
| `frontpage` | 报纸头版排版，头条+副条+简讯栏 |

## 参数

| 参数 | 必填 | 说明 |
| :--- | :--- | :--- |
| `size` | 是 | 视图尺寸，目前仅支持 `h4xl` |
| `source` | 否 | 新闻源，默认 `auto` 自动选择 |

## 测试链接

```
http://127.0.0.1:5000/news/view/frontpage?size=h4xl
```

## 新闻源

- 人民网 (RSS)
- 新华网 (RSS)
- 环球网 (RSS)

## 布局说明

h4xl (800×480) 报纸头版布局：
- 报头：标题 + 日期
- 头条区：48px 红色大字标题 + 摘要
- 四栏副条：32px 标题 + 摘要
- 底栏简讯：滚动式快讯
